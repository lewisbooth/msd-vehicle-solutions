## Architecture decisions

One Worker project deploys `dist` Static Assets and `worker/index.ts`. `assets.run_worker_first` selects public HTML paths, sitemap and `/api`; hashed CSS, JavaScript, fonts, graphics and the admin bundle bypass the script. The public JSX markup is rendered by React **inside the Worker only**, using D1 for current catalogue pages and tracked files for brochure/legal text. There is no public browser React bundle, build-time vehicle HTML or catalogue hydration. Missing paths and removed vehicles return a real 404.

Public APIs remain available: `GET /api/home`, `GET /api/vehicles?type=...`, `GET /api/vehicles/:slug`, `POST /api/contact`; admin APIs: `/api/admin/*`. Public HTML reads D1 directly without a second browser catalogue request. Admin edits become visible on the next HTML request; `Cache-Control: no-store` avoids publishing lag while retaining fingerprinted immutable assets. `src/content/vehicles.json` records the original live-only migration baseline and is not read by the public build. Filter GETs render their own selected cards in the first response. No archived backup records enter the app.

Workers Builds targets `main` for production with Build `npm run build` and Deploy `npm run deploy:production`. PR #1 has been squash-merged into `main`. Western Europe production D1/R2 contain only 15 current vehicles and 30 verified JPEGs. Production media temporarily uses `https://pub-f23343a6d1d74aca9ae43823407d11da.r2.dev`; switch to a custom R2 domain when the user moves DNS to Cloudflare. Preview Builds is disabled, both Preview lists are empty, and the preview D1/R2 and public preview media URL have been removed.
